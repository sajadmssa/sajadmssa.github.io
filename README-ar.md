# دليل التعديل السريع

## إضافة صور وريلز لخدمة
1. ضع الملفات في `assets/services/` (والفيديو في `assets/services/reels/`).
2. افتح `assets/media.js` وأضف سطرًا تحت رقم الخدمة (s1…s21) — الشرح والأمثلة في أعلى الملف.
3. يظهر في النسختين العربية والإنجليزية تلقائيًا، مع غلاف وعدّاد على البطاقة.

## ضبط النطاق (الدومين)
بعد معرفة رابط الموقع: `python3 tools/set-domain.py https://اسم-موقعك` — يحدّث canonical وصورة المشاركة وsitemap وrobots.

## السيرة المختصرة
`ar/cv/index.html` و`en/cv/index.html` (للطباعة A4)، وملفات PDF الجاهزة في `assets/cv/`.
