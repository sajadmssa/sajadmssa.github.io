# دليل الموقع

موقع سيرة وأعمال شخصي ثابت، متاح بالعربية والإنجليزية. ملفات الموقع ومجلد `assets/` موجودة في جذر المشروع. تتوفر أيضًا نسخة مستقلة جاهزة في `portfolio-site-v5.zip` داخل مجلد `portfolio-site-v5/`.

## المعاينة والنشر

1. افتح الطرفية في جذر المشروع وشغّل خادمًا محليًا:

   ```sh
   python -m http.server 8000
   ```

2. افتح `http://localhost:8000` لمعاينة الموقع. لا يحتاج الموقع إلى تثبيت حزم أو خطوة بناء.
3. قبل النشر، اضبط النطاق كما هو موضح أدناه، ثم انشر ملفات جذر المشروع إلى استضافة المواقع الثابتة مع الحفاظ على بنية المجلدات.

لمعاينة الحزمة المستقلة بدلًا من ملفات المشروع، فك ضغط `portfolio-site-v5.zip` وشغّل الخادم من مجلد `portfolio-site-v5`.

## بنية الموقع

- `index.html`: صفحة التوجيه إلى النسخة العربية.
- `ar/` و`en/`: الصفحتان الرئيسيتان والسيرتان الذاتيتان القابلتان للطباعة.
- `assets/`: التنسيقات والبرامج النصية والصور والخطوط وملفات PDF.
- `tools/set-domain.py`: تحديث روابط النطاق.

## ضبط النطاق

شغّل الأمر من داخل مجلد `portfolio-site-v5`، واستبدل الرابط بعنوان موقعك الكامل:

```sh
python tools/set-domain.py https://your-domain.example
```

يحدّث الأمر روابط `canonical` وبيانات المشاركة الاجتماعية وملفي `sitemap.xml` و`robots.txt`.

## إضافة وسائط للخدمات

1. ضع الصور في `assets/services/` ومقاطع الفيديو في `assets/services/reels/`.
2. أضف الوسائط إلى رقم الخدمة المناسب (`s1` إلى `s21`) في `assets/media.js`. يحتوي رأس الملف على أنواع الوسائط المدعومة وأمثلة الإعداد، وتظهر الوسائط في النسختين العربية والإنجليزية.

## تحديث السيرة الذاتية

- عدّل `ar/cv/index.html` و`en/cv/index.html` لنسختي الطباعة بحجم A4.
- ملفات PDF الجاهزة موجودة في `assets/cv/`.
